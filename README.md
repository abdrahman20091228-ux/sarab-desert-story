# سَـرَاب: ظهيرة الرمال (SARAB: Mirage of Noon — Chapter I)

لعبة قصصية ثلاثية الأبعاد (3D) بمنظور الشخص الأول باللغة العربية، مصممة للوضع الأفقي مع تحكم لمس عالي الحساسية للهواتف ودعم كامل للوحة المفاتيح والفأرة.

## القصة — الفصل الأول (من الظهر إلى العصر)
تستيقظ فجأةً وسط صحراء شاسعة تحت شمس الظهيرة الحارقة، بجوار بيتٍ مهجورٍ يحمل بقايا محطة رصد قديمة وبرج هوائي صدئ. بدون صوتٍ للبطل، تتكشف أفكاره عبر نصوص عربية أسفل الشاشة مصحوبة بصوت نقرات حوارية مولّدة برمجياً، ومع اكتشاف كل دليل يتقدم الوقت تدريجياً وعبر انتقالات سينمائية من **الظهيرة (١٢:١٥ ظهراً)** إلى **وقت العصر الذهبي (٤:٤٥ عصراً)** حيث ينكشف لغز «التردد ٤٤» والقبو المغلق تحت البيت.

## أبرز المميزات
- **شاشة دخول سينمائية 3D حية** بكاميرا تتحرك فوق الصحراء والبيت المهجور.
- **مشهد استيقاظ بصري متقن**: تفتّح الجفون تدريجياً وتلاشي الضبابية، ثم رفع الرأس نحو شمس الظهيرة بسطوع عالٍ وتوهج عدسة (Lens Flare + Eye Adaptation)، ثم إنزال الرأس والنهوض للتحكم الحر.
- **إضاءة ديناميكية ومخبوزة (Baked AO + Soft Shadows)** تتغير بسلاسة من الظهر إلى العصر مع سماء فيزيائية مخصصة (Rayleigh/Mie Sky Shader).
- **خامات PBR كاملة (Albedo + Normal + Roughness)** للرمال، جدران الطين المتصدعة، الخشب الصحراوي، المعدن الصدئ، الصخور الرملية، بلاط الأرضية، وقماش المظلة.
- **محرك صوتي برمجي كامل (Web Audio API)**:
  - صوت نقرات النص المتتابعة أثناء ظهور الحوار العربي.
  - صوت رياح الصحراء والرمال مع عزل صوتي واقعي عند الدخول إلى البيت.
  - خطوات تتغير حسب السطح (رمل ناعم في الخارج مقابل بلاط حجري في الداخل).
  - مؤثرات الاستيقاظ، سطوع الشمس، تقليب الورق، قاطع الكهرباء، وتشويش المذياع التناظري.
- **تحكم هواتف بالوضع الأفقي وحساسية لمس عالية** (قابلة للتعديل من `0.6x` إلى `4.0x`).
- **إعدادات جرافيك شاملة**: 4 مستويات جودة (منخفض / متوسط / عالي / فائق)، دقة العرض، الظلال، سطوع الشمس، مجال الرؤية FOV، ومؤشر الفريمات FPS.
