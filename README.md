# سَـرَاب — أثر القافلة المفقودة (SARAB v6.0)

لعبة غموض واستكشاف صحراوية عربية ثلاثية الأبعاد في المتصفح (WebGL / Three.js) تعمل بسلاسة على الهواتف والحاسوب عبر **أربعة فصول مترابطة** للبحث عن أخيك المفقود «سالم» منذ لهيب الظهيرة وحتى الليل المقمر تحت المجرة والنجوم.

## أبرز مزايا الإصدار v6.0

- **قصة تفاعلية متكاملة («أثر القافلة المفقودة»):**
  - **الفصل ١ (الظهر — سهول السراب):** تفحّص معسكر القافلة المهجور ورسالة سالم الممزقة، ثم شاهد السبخة المتشققة وساعته النحاسية قبل عبور البوابة الصخرية.
  - **الفصل ٢ (العصر — وادي الصخور والواحة):** استكشف أطلال الخان القديم ومذكرة سالم، ثم بئر واحة النخيل المظللة بسعف النخيل العربي.
  - **الفصل ٣ (الغروب والشفق — قمة جبل السراب):** تفقّد مأوى الراصد وخريطة النجوم، ثم انظر عبر المنظار النحاسي على القمة نحو بحر الكثبان الموحّد وبصيص نور البيت المهجور.
  - **الفصل ٤ (الليل المقمر — البيت المهجور):** رؤية ليلية واضحة بضوء القمر الفضي حتى دون الكشاف + كشاف يدوي فوري (0ms بدون تقطيع)، مع تفحّص وشاح سالم ودفتره ومصباح السطح.
- **إصلاحات بصرية وهندسية شاملة:**
  - حجب فيزيائي ثلاثي الأبعاد لوهج الشمس (`3D Sun Occlusion`) حتى لا تخترق الجبال أو الجروف أو الجدران.
  - سماء واقعية بسحب متوهجة وسديم مجرة ناعم ونجوم دقيقة وهلال مفصّل.
  - صخور رملية مصمتة (`Watertight Solid Boulders`) وجبال مندمجة طبيعياً مع التربة دون قواعد باهتة.
  - نخيل عربي واقعي بسعف ريشي مقوّس ولحاء حلقي، وإزالة الكثبان الصفراء الوهمية والعاصفة التي تخترق الجبال.
- **صوت محيطي ثلاثي الأبعاد حقيقي (`3D Spatial Audio`):**
  - ربط `AudioListener` بحركة الكاميرا ومصادر `PannerNode` لصراصير الليل في الصحراء وطقطقة الفوانيس وحفيف النخيل ونداءات الصقور والبوم وأصوات اكتشاف الأدلة بالعود.
- **واجهة HUD وUI معاد تصميمها بالكامل:**
  - شريط بوصلة معماري حي في الأعلى (`ش / ق / ج / غ`) مع مؤشر الهدف والمسافة، وبطاقة مهمة RTL مع نقاط التقدم، ونافذة اكتشاف الأدلة، بدون `backdrop-filter` للحفاظ على سلاسة 60 FPS.
- **الإعدادات الافتراضية:** بصريات فائق (`ultra`)، دقة العرض 140% (`1.4`)، حساسية اللمس والكاميرا `2.8x`، وتجهيز الشادرز مسبقاً أثناء شاشة الانتقال لمنع أي تقطيع أثناء الحركة أو فتح الكشاف.
